# DoIT

Notes and tasks kept as plain Markdown files on the user's own disk, arranged on shelves and reachable from a full window or a small floating one.

## Language

### Notes

**Note**:
One Markdown or text file in the notes folder, with a title and a body of lines and tasks.
_Avoid_: Card, tile (a tile is only how a note looks on the canvas)

**Shelf**:
A named place notes are filed on. A shelf exists on its own, even with no notes on it, and has a position, an icon and a collapsed state.
_Avoid_: Category, folder

**Uncategorized**:
The shelf that always exists, always comes last, and receives the notes of a deleted shelf.

**Settled**:
A note the user has put away: done with or not needed for a while, but kept. It leaves the canvas and its shelf, waits in the Settled view, and search still finds it. It keeps its shelf, so bringing it back returns it there.
_Avoid_: Archived, done, hidden

**Attachment**:
An image saved beside the notes and linked from a note, rather than stored inside its text.
_Avoid_: Embedded image, media

**External file**:
A Markdown or text file opened from outside the notes folder. It stays where it is and is only written when the user saves it.

### Modes

**Canvas**:
The full window, with every shelf and its notes laid out on a grid.
_Avoid_: Main window, dashboard

**Dock**:
The small always-on-top presence DoIT keeps on screen instead of the canvas. It is either the pill or the panel.
_Avoid_: Tray, companion, desk widget

**Pill**:
The dock at its smallest: a floating button that opens the panel.
_Avoid_: Floating bar

**Panel**:
The dock opened up: a compact note list and editor.
_Avoid_: Drawer, expanded tray

**Sheet**:
The editor that slides over the canvas when a note is open.
_Avoid_: Drawer

### Appearance

**Design**:
The overall interface style. Modern is the design on every OS; classic is the original one it replaced.
_Avoid_: Theme (a theme is a set of colours within a design), skin
